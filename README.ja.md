# WinMD

[English](README.md) | 日本語

Windows向けのMarkdownエディタです。**1文書につき1つの独立したウィンドウ**を開き、左でソースを編集し、右でプレビューを確認できます。タブはありません。アプリのUIは日本語です。

## インストール

**[Windows x64インストーラー v0.1.2](target/verified/x86_64-pc-windows-gnu/release/bundle/nsis/WinMD_0.1.2_x64-setup.exe)**

このリンクは作業フォルダー内の生成済みインストーラーです。GitHubでのリリース公開はまだ行っておらず、ソースのチェックアウトには含まれません。

1. インストーラーを実行します。対象はWindows 11 x64です。
2. WebView2 Runtimeがない場合、インストーラーがダウンロードして導入します。その場合はインターネット接続が必要です。
3. `.md`を関連付ける場合は、インストール時の案内で「はい」を選び、Windowsの既定アプリ設定で`.md`にWinMDを選択します。既定アプリを無断で変更することはありません。

現在のインストーラーは署名なしのGNU試用ビルドです。実GUI・インストールの受入確認は未完了です。[検証記録](docs/verification.md)を参照してください。

## 使い方

1. WinMDを起動し、**Ctrl+O**でMarkdownファイルを開きます。ファイルごとに別のウィンドウが開きます。
2. 左側で編集すると右側のプレビューが更新されます。中央の境界はドラッグで調整できます。
3. **Ctrl+S**で保存します。新規文書は最初に保存先を選びます。
4. 画像をコピーして**Ctrl+V**を押すと、文書と同じフォルダーに`20261026_231824.png`形式で保存し、画像リンクを挿入します。未保存文書では先に文書を保存します。同名画像は上書きしません。
5. Codexなどが外部でファイルを更新すると、未保存の編集がなければ自動反映します。WinMDでも編集中の場合は、編集を保持して競合を通知します。

画像貼り付けはPNG/JPEG/GIF/WebPに対応し、PNGとして保存します。上限は16 MiB・16メガピクセルです。同じ秒の同名画像がある場合は、1秒待って再度貼り付けてください。

## 主なショートカット

| 操作                           | キー                                |
| ------------------------------ | ----------------------------------- |
| 新しい文書を別ウィンドウで開く | Ctrl+N                              |
| ファイルを開く                 | Ctrl+O                              |
| 保存 / 名前を付けて保存        | Ctrl+S / Ctrl+Shift+S               |
| 画像・テキストの貼り付け       | Ctrl+V                              |
| 検索 / 置換                    | Ctrl+F / Ctrl+H                     |
| Undo / Redo                    | Ctrl+Z / Ctrl+Y または Ctrl+Shift+Z |
| 現在のウィンドウを閉じる       | Ctrl+W / Alt+F4                     |

## ファイルとプレビュー

- UTF-8のBOM有無、LF/CRLF、末尾改行の有無を保持します。改行混在の文書は読み取り専用です。
- 原本への自動保存やクラッシュ復元はありません。変更はCtrl+Sで保存してください。
- 生HTMLはエスケープし、プレビューをサニタイズします。外部画像は初期状態でブロックし、文書ごとに許可できます。
- ローカル画像は文書フォルダー配下に限定します。文書は32 MiB以下、ローカル画像は1枚16 MiB以下・先頭100件までです。

## 開発

Tauri 2、TypeScript、Vite、CodeMirror 6、marked、DOMPurify、Rustで実装しています。

```powershell
$env:CI='true'
pnpm install --frozen-lockfile
pnpm desktop:dev
```

検証は`pnpm check`、`pnpm test`、`pnpm lint`、Windows用ビルドは`pnpm desktop:build`です。Rust・MSVC・WebView2などの前提条件と詳しいコマンドは[開発・ビルドガイド](docs/development.md)を参照してください。
