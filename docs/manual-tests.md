# Windows GUI受入手順

## 公開用README・スクリーンショット

- 両READMEの先頭で画面が表示され、各画像の代替テキスト・英語サンプルの「UIは日本語」という説明が一致すること。
- `docs/examples/notes.ja.md`と`notes.en.md`をWinMDで開き、見出し・チェックリスト・表・コードがスクリーンショットと対応すること。Alt+FでPDF出力・印刷・ショートカットが見えること。
- 画像にはユーザーの実文書・ダイアログ・ほかのアプリを含めないこと。更新時は`docs/screenshots/README.md`の手順を使うこと。
- GitHub公開後、非ログイン状態でREADMEの画像、言語切り替え、Releasesへのリンクを確認すること。インストーラー公開後に「公開準備中」の説明を実際の配布状況へ更新すること。
- 告知文の「公開しました」は、実際に公開した後で使うこと。投稿時には添付画像と代替テキストも確認すること。

## 0.1.7の本文領域

- メニュー直下から左右の編集・プレビュー領域が始まり、「MARKDOWN／ソース」「PREVIEW／プレビュー」の見出し行や余った空白がないこと。左右分割、スクロール、幅変更、メニュー、PDF/印刷が引き続き使えること。

## 0.1.6のタイトル表示

- 日本語・空白・括弧を含むパスの文書を開き、タイトルが`無題.md (C:\Users\saru\Desktop\無題.md)`の形式になること。メニュー直下のフルパス行は表示しないこと。
- canonicalな`\\?\C:\...`は`C:\...`、`\\?\UNC\server\share\...`は`\\server\share\...`としてタイトルに表示すること。表示の加工だけで、保存・画像参照に使うパスを変えないこと。
- 新規文書は「無題」、変更後は先頭に`*`、保存後は`*`が消えること。名前を付けて保存するとファイル名と括弧内のフルパスが両方更新されること。

## 0.1.5の編集メニュー

- Alt+Eと「編集 (E)」クリックでメニューを開く。項目の右にCtrl+Z/X/V、Del、Ctrl+F、F3、Shift+F3、Ctrl+H、F5が表示されること。左右矢印でファイル/編集を移動し、上下・Home/End・Enter・Escで操作できること。最小ウィンドウではメニュー内をスクロールできること。
- 選択範囲の切り取り・テキスト貼り付け・削除をメニューから実行し、元に戻せること。選択なし・Undo履歴なし・読み取り専用では対応する項目を無効にすること。検索欄内のCtrl+X/V/Zはその欄を操作すること。
- 検索語が2箇所以上ある日本語本文で検索・次・前・置換を試し、末尾/先頭から折り返すこと。プレビューからAlt+E、Ctrl+F/H、F3/Shift+F3も確認すること。
- 画像をコピーしてメニューの貼り付けを選び、従来のCtrl+Vと同じPNG保存・リンク挿入・Undoが動くこと。未保存文書で保存キャンセル、同名PNG、クリップボードが他アプリで使用中の場合に本文を保持すること。読み取り待ち中にカーソルを移した場合は挿入を中止すること。
- F5またはメニューからタイムスタンプを挿入。0.1.8以降はPCローカル時刻の`2026/01/27 08:38:02`（`yyyy/mm/dd hh:mm:ss`、24時間制）になり、月日・時分秒が2桁になること。カーソル位置への挿入/選択置換・Undo/Redoを確認し、F5でWebViewが再読み込みされないこと。画像の保存名は`YYYYMMDD_HHMMSS.png`を維持すること。
- IME変換・再変換中、PDF準備中、保存確認ダイアログ中に誤編集しないこと。クリップボードを開くのは明示した切り取り・貼り付け時だけで、メニューを開くだけでは読み取らないこと。

## 0.1.4の上部バー

- 右上に「検索・置換」と「この文書の外部画像を許可」が表示されないこと。左上は「ファイル (F)」でFに下線があり、Alt+Fで開くこと。検索・置換は編集領域でCtrl+F／Ctrl+Hを使用すること。
- 印刷・PDF出力を再実行し、削除したコントロールの参照エラーがなく本文が出力されること。0.1.4では外部画像の許可UIを削除したため、以下の旧版手順Pの許可切り替えは対象外。外部画像のブロックと明示クリックした安全なリンクの動作を確認する。

## 0.1.1の追加試験

- スクリーンショットをコピーし、保存済みの日本語パスの文書へCtrl+V。文書と同じフォルダーに年月日_時分秒.pngが作られ、リンク・プレビューが一致すること。通常テキスト貼り付け、選択範囲への貼り付け、Undo/Redoも確認。
- 新規文書への画像貼り付けでMarkdown保存をキャンセル。画像ファイルもリンクも作られないこと。保存完了ならそのフォルダーへ画像が作られること。
- 同一秒の画像貼り付けと同名既存画像、保存先が読み取り専用の場合。上書きや失敗リンク挿入がないこと。画像処理中の入力・閉じる・別名保存・再読み込みの順序も確認。
- JPEG/GIF/WebPのクリップボード画像がPNGになること。SVG、壊れたPNG、上限超過を拒否すること。IME変換中のCtrl+Vも手動確認。
- 表Jの外部変更試験では、WinMDがcleanなら**操作なしで**ソースとプレビューに更新されること。Codexの直接書き込み・一時ファイル置換の両方を試す。dirtyの場合は両方の編集を保持し、無確認の自動置換をしないこと。
- 新NSISを対話インストールし、既定アプリ設定を開く質問で「いいえ」なら既定値不変、「はい」ならWinMD設定へ進めること。ユーザーが.mdの既定にWinMDを選んだ後、エクスプローラーのダブルクリック・追加起動を確認。アンインストールでRegisteredApplications/Capabilitiesも解除すること。サイレントインストールでは設定画面を開かないこと。

## 0.1.2の関連付け回帰試験

- `scripts/test-associations.ps1`で、実際のNSIS書き込み行を隔離キーへ書く試験を実行。空白・括弧・日本語を含む仮のインストール先で、3つのopen commandと3つのアイコン値が正確に引用されること。値に余計な`$`を含めないこと。
- 既定アプリをユーザーがWinMDに選んだ環境で、空白・日本語を含むテスト用.mdをシェル経由で起動し、正しいファイル名のウィンドウが開くことを確認。直接exeを起動するだけでは関連付け試験の代わりにしない。
- 0.1.1の不正登録を修復する試験では変更前の値をバックアップし、UserChoiceのProgId/Hashが不変であることを確認する。ユーザーの本物の文書は変更しない。

## 0.1.3のメニュー・PDF・印刷

- 「ファイル」クリックとAlt+Fでメニューを開く。項目の右にCtrl+N/O/S/Shift+S/Pが表示されること。矢印・Home/End・Enter・Esc、外側クリック、Tabによる移動を確認する。読み取り専用では保存項目を飛ばすこと。タブや画面内のWinMDロゴがなく、タイトルは文書名だけになること。
- 編集領域とプレビューそれぞれにフォーカスした状態でCtrl+N/O/S/P、Alt+Fを試す。新しいウィンドウが独立し、Ctrl+Pで本文の印刷画面が1回だけ開くこと。IME変換中や保存確認の表示中に誤実行しないこと。
- 未保存の日本語本文、表、チェックリスト、長いコード、ローカルPNG、外部画像ブロックの文書をPDF出力する。保存先は日本語・空白を含むテストフォルダーを使用。A4縦で本文だけが複数ページに出力され、メニュー・エディタ・ステータスが混ざらず、日本語が欠けないこと。Markdownの内容とdirty状態を保持すること。
- PDFの保存先選択・上書き確認をキャンセルし、既存PDFとMarkdownが変わらないこと。PDF出力中に保存先を外部更新した場合は上書きを拒否すること。.md指定、開いている文書の別名リンク、書き込み不可、画像読み込み失敗も安全に止まること。
- Ctrl+Pで実プリンターとMicrosoft Print to PDFを選び、プレビュー・ページ範囲・キャンセルを確認する。PDF/印刷の準備中に重ねて実行しても多重処理されないこと。
- dirtyな2文書とcleanな1文書で「終了」。文書ごとに保存確認し、キャンセルした文書の編集が残ること。
- 非表示WebView2のGNU回帰プローブはWSLで `bash scripts/build-print-probe-wsl.sh` を実行して生成する（Common Controls v6マニフェストも埋め込む）。Windowsで `target/verified/x86_64-pc-windows-gnu/release/examples/print_smoke.exe <未作成のテストPDFの絶対パス>` を実行し、生成PDFのA4寸法・日本語・末尾のEND_OF_DOCUMENT・SHOULD_NOT_PRINT不在を確認し、全ページをPNGにレンダリングして目視する。このプローブは固定fixtureをlocalhostで読み込む。ネイティブPDF生成と印刷CSSの検証であり、ファイル選択や実プリンターのGUI受入の代わりにはしない。
