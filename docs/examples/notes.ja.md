# 書いて、すぐにプレビュー

**SaruMD** で、日々のメモをMarkdownに。
左で編集しながら、右で仕上がりを確認できます。

## 今日のメモ

- [x] アイデアを箇条書きにする
- [x] 表で情報を整理する
- [ ] 完成した文書をPDFにする

## よく使う操作

| 操作         | キー   |
| ------------ | ------ |
| 保存         | Ctrl+S |
| 画像貼り付け | Ctrl+V |
| 日時挿入     | F5     |
