# SaruMDの公開告知案

以下はTwitter（X）へ手動投稿するための文面案です。リポジトリと[SaruMD v0.1.13インストーラー](https://github.com/sarulab-ou/SaruMD/releases/tag/v0.1.13)は公開済みです。Twitterへの投稿はまだ行っていません。

## まず使う案：公開後の告知

GitHubのソースと試用版インストーラーを紹介する文面です。

```text
Windows向けMarkdownエディタ「SaruMD」を公開しました。

・左で編集、右でプレビュー
・Ctrl+Vで画像を保存＆挿入
・PDF出力・印刷
・外部ツールの更新も反映（未保存の編集がない場合）

1文書1ウィンドウのシンプルなエディタです。MITライセンス。
https://github.com/sarulab-ou/SaruMD
#Markdown #Windows
```

添付は[編集画面のPNG](screenshots/editor-ja.png)を1枚使います。

画像の代替テキスト案：

「SaruMDの実画面。左にMarkdownのソース、右に見出し・チェックリスト・表・コードのプレビュー。同じ内容を並べて確認できる。」
