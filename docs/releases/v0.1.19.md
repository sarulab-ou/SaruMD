# SaruMD v0.1.19 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.19_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.19/SaruMD_0.1.19_x64-setup.exe)**

リンク先のURL・ファイルパスをマウス付近の吹き出しに表示します。

## v0.1.18からの変更

- ソース・プレビューのリンクに約0.35秒マウスを重ねると、リンク先をポップアップ表示します。フッター表示も維持します。
- プレビューのローカルリンクも、実際のファイル参照を表示します。
- 長いリンク先は枠内で折り返し、画面内に収まる位置へ調整します。
- マウス離脱・スクロール・クリック・文字のドラッグ選択・Escなどで消えます。ポップアップがクリックを遮ることはなく、hoverで外部通信やファイル読み込みは行いません。

## インストール

1. 編集中の文書を保存し、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.19_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.19/README.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.19/docs/verification.md)

## 確認範囲

型検査、Vitest 63件、ESLint、Prettier、フロントエンドビルド、Rustテスト（Linux16件・Windows17件）・clippy・fmt、Windows向けビルド、NSIS生成と同梱ファイル照合を実施しました。

隔離したEdgeで両ペインのHTTP URL・Markdown・JSONの6通りについて、吹き出しの内容・画面内配置・離脱後の消去と保存状態への復帰を確認しました。従来のクリック配送、文字選択、読み取り専用、本文・Undoの不変も確認し、検証画面のPNGを目視確認しています。外部起動は代替関数による検査です。Windows/WebView2実アプリでのポップアップと、インストーラー全体のGUI受入は未実施です。
