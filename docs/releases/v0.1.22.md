# SaruMD v0.1.22 — Preview / 試用版

**[初回導入用Windows x64インストーラーをダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.22/SaruMD_0.1.22_x64-setup.exe)** · [更新用ZIP](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.22/SaruMD_0.1.22_x64-update.zip)

アプリ内の更新を、ZIPを取得してファイルを置き換える方式へ変更しました。0.1.22以降を導入した後の更新では、インストーラーを起動しません。

## v0.1.21からの変更

- 「ヘルプ (H) → 更新…」で新しい公開版を確認し、更新用ZIPをダウンロードします。サイズ・SHA-256・展開内容・バージョンを検証してから終了確認へ進みます。
- 未保存の変更は各文書で保存確認します。キャンセルすると更新も止めます。
- 文書を閉じて旧プロセスが終了した後、実行ファイル・DLL・ライセンスを置き換えて再起動します。
- 置き換えに失敗した場合は旧ファイルへ戻し、旧版の再起動を試みます。復元できない場合はバックアップを保持して場所を通知します。
- 更新中の別起動はロックの解除を待ちます。関連付け・文書・設定・アンインストーラーは変更しません。
- Windows PowerShellの環境差を避けるため、補助プロセスの呼び出しも調整しました。

## この版への移行

**0.1.21の更新機能は従来のインストーラー方式です。ZIP方式へ切り替える最初の1回は、次のいずれかで導入してください。**

1. 文書を保存してSaruMDを終了し、上のインストーラーを実行します。初めて使う場合もこちらを選んでください。
2. インストール済みの場合は、終了後に上のZIPを展開し、中のファイルを同じフォルダー構成でアプリの配置先へコピーすることもできます。既存のアンインストーラーや文書を削除する必要はありません。

0.1.20以前には更新メニューがありません。ZIPはWebView2 Runtimeや関連付けを導入しないため、初回導入にはインストーラーを使用してください。

Windows 11 x64向けの署名なしGNUビルドを試用版として配布します。自動保存・クラッシュ復元はありません。更新の確認は手動操作です。

## 確認範囲

型検査、Vitest 69件、ESLint、Prettier、フロントエンドビルド、Rustテスト（Linux20件・Windows22件）・clippy・fmt、Windows向けビルド、NSIS/ZIP生成・展開・同梱ファイル照合を実施しました。

隔離した模擬アプリで終了待ち・置き換え・再起動・DLLロック時と起動失敗時の復元を確認しました。ZIPの不正パス・重複・リンク属性・サイズ/版/ハッシュの違いも拒否します。製品と同じRust/PowerShell経路で、生成したZIPを検証しています。実アプリの保存確認からZIP更新・再起動までのGUI受入、MSVCビルドは未実施です。複数ファイル全体の原子性や電源断からの自動復元は保証しません。
