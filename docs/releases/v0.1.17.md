# SaruMD v0.1.17 — Preview / 試用版

ローカルファイルへのMarkdownリンクをクリックして開けるようにしました。

## v0.1.16からの変更

- `[今回の記録](latest-continuation.md)`や`[JSON](summary.json)`を、ソース・プレビューの両方から開けます。ソース側はインライン形式のリンクに対応します。
- 相対パスは、開いているMarkdownと同じフォルダーが基準です。親フォルダー、日本語・空白入りのパス、URLエンコード、ドライブ名付き絶対パス、ローカルの`file:///`も扱えます。
- MarkdownはSaruMDで開き、既に開いている同じ文書があればそのウィンドウへ移動します。JSON・PDF・Excelなどの文書はWindowsの既定アプリで開きます。
- 存在しないファイルなどは画面下部へ理由を表示します。実行ファイル・スクリプト・ショートカット、リモート指定のファイルリンクは開きません。

別のPCへ文書を移す場合は、リンク先のファイルも相対位置を保ってコピーしてください。相対リンクは文書の保存後に使えます。リンク先の見出しへの位置移動は未対応です。

## インストール

1. 編集中の文書を保存し、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.17_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.17/README.md) · [リンクのサンプル](https://github.com/sarulab-ou/SaruMD/blob/v0.1.17/docs/examples/links.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.17/docs/verification.md)

## 確認範囲

型検査、Vitest 63件、ESLint、Prettier、フロントエンドビルド、Rustテスト（Linux16件・Windows17件）・clippy・fmt、Windows向けビルド、NSIS生成と同梱ファイル照合を実施しました。隔離したEdgeで両ペインの通常クリック、ドラッグ選択、読み取り専用、スクロール・数式・印刷DOMも検査しています。

生成した実アプリで、プレビューからMarkdownが開くこと、ソースから同じMarkdownのウィンドウへ戻ること、JSONがこのPCの既定アプリであるVS Codeで開くことを確認しました。別マシンでの再確認、PDF/Excelの実アプリ起動、インストーラー全体のGUI受入は未実施です。
