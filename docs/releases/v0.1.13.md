# SaruMD v0.1.13 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.13_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.13/SaruMD_0.1.13_x64-setup.exe)**

編集中のファイルのフルパスを表示するアドレスバーを追加しました。

## 変更点

- メニューの下に、現在のファイルのフルパスを表示します。先頭の`\\?\`は除いて表示します。
- **Alt+D**でアドレスバーへ移動してパスを全選択し、**Ctrl+C**でコピーできます。ソース側・プレビュー側・メニュー操作中から利用できます。
- アドレスバーは読み取り専用です。新規文書では「未保存の文書」と表示し、保存・名前を付けて保存の成功後は現在の保存先へ更新します。
- 本文の編集中は、パスの選択と横スクロールを保持します。PDF・印刷にはアドレスバーを含めません。

## インストール

1. 編集中の文書を保存して、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.13_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。アプリUIは日本語です。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.13/README.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.13/docs/verification.md)
