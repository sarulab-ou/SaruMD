# SaruMD v0.1.15 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.15_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.15/SaruMD_0.1.15_x64-setup.exe)**

ソースとプレビューのURLをクリックして、既定のブラウザで開けるようにしました。

## v0.1.13からの変更

- ソースのHTTP/HTTPSのURLに下線を表示し、通常クリックで既定のブラウザへ渡します。`www.`で始まるURLにも対応します。
- プレビューのリンクに加え、コード内などのURLもクリックできます。
- URL末尾の句読点やMarkdownの閉じ括弧を除いて開きます。ドラッグでの文字選択、本文とUndo履歴を保持します。読み取り専用文書でもクリックできます。
- アドレスバー左側の「アドレス」という見出しを削除しました。Alt+Dでパスを全選択する操作は引き続き使えます。

## インストール

1. 編集中の文書を保存し、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.15_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。アプリUIは日本語です。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.15/README.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.15/docs/verification.md)

## 確認した範囲

60件のフロントエンドテスト、型検査・lint・ビルド、RustのLinux14件/Windows15件のテスト・clippy・fmtが成功しました。隔離Edgeのtrustedマウス入力で、ソース・プレビュー・コード内URL・読み取り専用ソースから正しいURLが外部リンク処理へ渡ることを確認しました。合成clickとドラッグ選択での起動防止、本文とUndoの不変、既存のスクロール・ソース移動・数式の印刷DOMも確認しています。

ブラウザ起動はモックによる配送試験です。実アプリからOSの既定ブラウザを起動するGUI受入と、インストーラー全体の受入は未完了です。詳細は検証記録を参照してください。
