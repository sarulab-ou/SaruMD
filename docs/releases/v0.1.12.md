# SaruMD v0.1.12 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.12_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.12/SaruMD_0.1.12_x64-setup.exe)**

WinMDをSaruMDへ名前変更しました。GitHubリポジトリは[sarulab-ou/SaruMD](https://github.com/sarulab-ou/SaruMD)です。

## 変更点

- アプリ、実行ファイル、インストーラー、関連付け、エラー表示の名前をSaruMDへ変更しました。実行ファイルは`SaruMD.exe`です。
- 同じファイルを再度開くと既存文書を利用し、既存ウィンドウを表示・最小化解除してフォーカスする処理を補強しました。未保存の編集は保持します。
- v0.1.11のTeX数式表示、PDF出力・印刷、左右のスクロール連動、プレビューからソースへの移動を引き継いでいます。

## インストールと旧版からの切り替え

1. WinMD / SaruMDで編集中の文書を保存して終了します。旧版を起動したままだと、起動要求が旧プロセスへ転送されます。
2. Assetsの`SaruMD_0.1.12_x64-setup.exe`をWindows 11 x64で実行します。WebView2 Runtimeがない場合は、インストーラーがダウンロードします。
3. `.md`をダブルクリックで開きたい場合は、Windowsの既定アプリ設定でSaruMDを選択します。旧WinMDの関連付けは自動変更しません。
4. 旧WinMDはWindowsの設定から別途アンインストールできます。

署名なしのGNUビルドを試用版として配布します。アプリUIは日本語です。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.12/README.md) · [数式のサンプル](https://github.com/sarulab-ou/SaruMD/blob/v0.1.12/docs/examples/math.md)

## 確認した範囲

56件のフロントエンドテスト、型検査・lint・ビルド、RustのLinux14件/Windows15件のテスト・clippy・fmtが成功しました。関連付けの実NSIS行を隔離環境で検証し、既定アプリ設定が変更されないことを確認しました。

実デスクトップでは相対パスとhard link経由で同じ文書を開き、既存の1プロセス・1ウィンドウを維持することを確認しました。生成したv0.1.12をユーザーが起動確認し、公開の承認を受けています。

最小化からの復元とOSの前面フォーカスの実操作、実プリンター、インストーラー全体の受入確認は未完了です。詳しくは[検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.12/docs/verification.md)を参照してください。
