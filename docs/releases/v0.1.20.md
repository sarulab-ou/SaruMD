# SaruMD v0.1.20 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.20_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.20/SaruMD_0.1.20_x64-setup.exe)**

印刷用の文書名を、PDFエクスポートと同じ「元のファイル名の拡張子を.pdfに置き換えた名前」に揃えました。

## v0.1.19からの変更

- `sample.md`なら`sample.pdf`、`議事録.v2.md`なら`議事録.v2.pdf`を印刷用の名前にします。
- 新規未保存文書は`無題.pdf`になります。名前を付けて保存した後は、新しいファイル名へ更新します。
- PDFエクスポートの既定名も同じ形式です。通常のタイトルバーは従来どおり`ファイル名 (フルパス)`を表示します。

## インストール

1. 編集中の文書を保存し、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.20_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.20/README.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.20/docs/verification.md)

## 確認範囲

型検査、Vitest 64件、ESLint、Prettier、フロントエンドビルド、Rustテスト（Linux16件・Windows17件）・clippy・fmt、Windows向けビルド、NSIS生成と同梱ファイル照合を実施しました。

命名試験で日本語・空白・複数のドット・大文字のMD・markdown拡張子・未保存などを確認しました。実際のrefresh関数を使うDOM確認でも、保存先変更に応じた印刷用タイトルの更新とアドレス表示の保持を確認しています。ネイティブタイトルのIPCは代替関数です。Windows/WebView2の印刷/PDF保存ダイアログ、Microsoft Print to PDFなどのドライバー別既定名、実プリンターへの印刷、インストーラー全体のGUI受入は未検証です。
