# SaruMD v0.1.16 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.16_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.16/SaruMD_0.1.16_x64-setup.exe)**

「ヘルプ (H)」メニューと「バージョン情報」を追加しました。

## v0.1.15からの変更

- Alt+Hでヘルプメニューを開けます。プレビュー側にフォーカスがある場合も使えます。
- 「バージョン情報」にアプリ名、実行中のバージョン番号、MITライセンスを表示します。
- 左右の矢印キーでファイル・編集・ヘルプの各メニューを移動できます。

## インストール

1. 編集中の文書を保存し、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.16_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。アプリUIは日本語です。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.16/README.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.16/docs/verification.md)

## 確認範囲

型検査、Vitest 60件、ESLint、Prettier、フロントエンドビルド、Rustテスト・clippy・fmt、Windows向けビルド、NSIS生成と同梱ファイル照合を実施しました。DOM確認ではAlt+Hとバージョン情報の内容を確認しました。この確認ではバージョン取得とダイアログの表示APIを代替しています。

実アプリのヘルプ・バージョン取得と、インストーラー全体のGUI受入は未実施です。ローカルファイルへのリンクを開く機能は今回の変更に含まれません。
