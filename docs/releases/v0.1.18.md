# SaruMD v0.1.18 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.18_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.18/SaruMD_0.1.18_x64-setup.exe)**

リンクにマウスを重ねると、フッターにリンク先を表示するようにしました。

## v0.1.17からの変更

- ソース・プレビューの両ペインで、Web URLとローカルファイルのリンク先を表示します。
- ローカルリンクでは内部用のURLではなく、`linked-note.md`などの実際のリンク参照を表示します。
- マウスを離すと通常の保存状態表示へ戻ります。hover中に保存状態やエラーが更新された場合も、最新の表示を保持します。
- 長いリンク先はフッター内で1行に省略します。hoverだけでファイルや外部アプリを開くことはありません。

## インストール

1. 編集中の文書を保存し、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.18_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.18/README.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.18/docs/verification.md)

## 確認範囲

型検査、Vitest 63件、ESLint、Prettier、フロントエンドビルド、Rustテスト（Linux16件・Windows17件）・clippy・fmt、Windows向けビルド、NSIS生成と同梱ファイル照合を実施しました。

隔離したEdgeで、両ペインのHTTP URL・Markdown・JSONの6通りのマウス移動による表示と解除、最新の保存表示への復帰を確認しました。従来のクリック配送、文字選択、読み取り専用、本文・Undoの不変も確認しています。外部起動は代替関数による検査です。Windows/WebView2実アプリでのhoverと、インストーラー全体のGUI受入は未実施です。
