# WinMD v0.1.8 — Preview / 試用版

Windows向けMarkdownエディタWinMDの初回公開リリースです。アプリUIは日本語です。

## ダウンロードとインストール

1. Assetsから`WinMD_0.1.8_x64-setup.exe`をダウンロードし、Windows 11 x64で実行してください。
2. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。
3. `.md`をダブルクリックで開く場合は、Windowsの既定アプリ設定でWinMDを選択してください。

## 主な機能

- 左でMarkdownを編集、右でライブプレビュー。1文書1ウィンドウ。
- Ctrl+Vで画像をPNG保存し、Markdownリンクを挿入。
- 外部ツールの更新を自動反映。未保存の編集がある場合は保持して競合を通知。
- PDF出力・印刷、検索・置換、F5で日時挿入。
- MITライセンス。

## 試用版について

署名なしのWindows x64 GNUビルドです。インストール・実GUI全体の受入確認は未完了です。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。アプリUIの英語対応はありません。詳しい確認範囲は[検証記録](https://github.com/sarulab-ou/winmd/blob/v0.1.8/docs/verification.md)を参照してください。

---

The first public preview of WinMD, a Markdown editor for Windows. **The application UI is currently Japanese.**

## Download and install

Download `WinMD_0.1.8_x64-setup.exe` from Assets and run it on Windows 11 x64. The installer downloads WebView2 Runtime if needed. To open `.md` files by double-clicking, select WinMD in Windows' default app settings.

## Highlights

- Markdown source and live preview side by side; one document per window.
- Ctrl+V image paste saves a PNG and inserts its Markdown link.
- External changes reload automatically when there are no unsaved edits; conflicting edits are preserved and reported.
- PDF export, printing, find/replace, and F5 timestamps.
- MIT licensed.

## Preview status

This is an unsigned Windows x64 GNU build. Installation and full GUI acceptance testing remain incomplete. There is no autosave or crash recovery; save with Ctrl+S. See the [verification record](https://github.com/sarulab-ou/winmd/blob/v0.1.8/docs/verification.md) for the tested scope.
