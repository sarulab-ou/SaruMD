# SaruMD v0.1.21 — Preview / 試用版

**[Windows x64インストーラー（SaruMD_0.1.21_x64-setup.exe）をダウンロード](https://github.com/sarulab-ou/SaruMD/releases/download/v0.1.21/SaruMD_0.1.21_x64-setup.exe)**

「ヘルプ (H) → 更新…」から、GitHubの新しいバージョンを確認・ダウンロードして更新できるようにしました。

## v0.1.20からの変更

- 公開済みのリリース（試用版を含む）から現在より新しい版を探し、バージョンとサイズを表示します。
- 「ダウンロードして更新」を選ぶと、配布ファイルのサイズとSHA-256を照合します。通信や検証に失敗した場合はインストールしません。
- 検証後、各文書を順に閉じます。未保存の変更は通常の保存確認を行い、キャンセルすると更新を止めて残る文書を保持します。
- すべての文書の終了確認後、旧プロセスの終了を待ち、同じインストール先へ更新してSaruMDを再起動します。
- 複数ウィンドウからの同時更新を防ぎ、終了確認中は文書の新規作成・オープンを止めます。

## インストール

**0.1.20以前には更新メニューがありません。この版への初回更新は、インストーラーで行ってください。** 0.1.21以降を導入すると、今後の更新でこのメニューを使えます。

1. 編集中の文書を保存し、起動中のWinMD / SaruMDを終了します。起動したままだと、起動要求が旧プロセスへ転送されます。
2. 上のリンクまたはAssetsから`SaruMD_0.1.21_x64-setup.exe`をダウンロードし、Windows 11 x64で実行します。
3. WebView2 Runtimeがない場合は、インストーラーがダウンロードします。

署名なしのGNUビルドを試用版として配布します。自動保存・クラッシュ復元はありません。Ctrl+Sで保存してください。更新の確認は手動操作のみで、定期的な自動チェックは行いません。

[使い方](https://github.com/sarulab-ou/SaruMD/blob/v0.1.21/README.md) · [検証記録](https://github.com/sarulab-ou/SaruMD/blob/v0.1.21/docs/verification.md)

## 確認範囲

型検査、Vitest 69件、ESLint、Prettier、フロントエンドビルド、Rustテスト（Linux20件・Windows21件）・clippy・fmt、Windows向けビルド、NSIS生成と同梱ファイル照合を実施しました。

GitHubの公開版0.1.20の実ダウンロード・SHA-256照合、更新なしの判定、メニューとダイアログ、キャンセルや保存失敗の処理を確認しました。補助プロセスの終了待ち・引数・一時ファイル削除は模擬インストーラーで検査しています。実際の上書きインストールから再起動までのWindows/WebView2 GUI受入とMSVCビルドは未実施です。
