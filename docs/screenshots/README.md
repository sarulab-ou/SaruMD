いずれも1182×831ピクセルのJPEGです。撮影APIから取得した画像を再圧縮せず保存しています。タイトルバーは実際の表示のため、サンプル文書のローカルパスを含みます。アプリUIは日本語で、英語の画像は本文だけを英語にしています。

## 撮り直す手順

1. WinMDで[日本語サンプル](../examples/notes.ja.md)または[英語サンプル](../examples/notes.en.md)を開きます。
2. 標準サイズのウィンドウで、分割を50%にし、ソースとプレビューを先頭へスクロールします。
3. 通知やほかのウィンドウを写さず、見出し、チェックリスト、表、コードが読める状態でウィンドウを撮影します。
4. メニュー画像は日本語サンプルでAlt+Fを押し、「PDFにエクスポート」と「印刷」が見える状態を撮影します。撮影後はEscで閉じます。
5. 画像を差し替えたらREADMEの表示・代替テキストと、この文書のバージョン・寸法を確認します。

画像はこのリポジトリの[MITライセンス](../../LICENSE)で使用できます。告知文と画像の代替テキスト案は[公開告知案](../announcement.md)にあります。
